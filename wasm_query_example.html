Local WASM Text Embedding for Video Search

Instead of spinning up an expensive cloud GPU for every search query, this in-browser client generates a 768-dimensional text embedding locally using WebAssembly (WASM) / WebGPU via Transformers.js. The resulting vector directly matches the video vectors stored in Pinecone with $0.00 cloud GPU spend.
